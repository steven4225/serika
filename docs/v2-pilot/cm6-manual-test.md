# CM6 macOS 手动测试

在 `experiment/architecture-v2` 检出根目录运行，需已安装 pnpm/依赖。模型固定 `deepseek/deepseek-v4.1-flash-fast`，32K 窗口、有效输入 26,624；启动命令自动构建。密钥只从当前终端的 `COMMAND_CODE_API_KEY` 或测试专用 `~/.serika-test.env` 读取，可用 `SERIKA_CM6_TEST_ENV_FILE` 指定另一份测试 env。不读取日用配置、profile 或聊天；不要把密钥贴入聊天。

两条命令：

```sh
pnpm manual:cm6 --fault-unknown-write=notes/uncertain-manual.txt
pnpm manual:cm6:export
```

普通启动复用同一隔离目录。首行会打印目录，它位于 macOS 临时目录下 `serika-cm6-manual-<uid>-<实验检出路径hash>/test-<uuid>/`，内部 profile、home、config、workspace、transcripts 独立。`--fresh` 新建测试并切换当前目录，旧目录和导出保留；冷启动时不要加它。系统清理临时目录会丢失测试，请及时导出。启动器终端保持运行，不操作日用 Serika。

| 步骤 | 输入或操作 | 预期看到什么 |
|---|---|---|
| 1 | 执行第一条命令。首次需要从零开始时加 `--fresh`，故障参数保持不变 | 新窗口标题为“Serika · 隔离测试”，终端显示隔离路径、32K 和故障路径。没有自动发送模型请求 |
| 2 | 输入：`我们正在整理灯塔项目材料。目标：完成验收报告。已确认决定：采用本地文件方案。待办：补充失败样本。部署未获批准，不要部署。记住：我希望报告先给结论。请简短确认。` | 回答确认任务；如申请记忆写入则仅批准该次。打开记忆页看“我希望报告先给结论”是否实际保存，未保存也如实留档；回到聊天 |
| 3 | 输入：`请只调用一次 read_file 读取 notes/brief.txt，告诉我是否成功，不读其他文件。` 仅批准这次读取 | 工具成功，内容包含“验收报告、来源证据、失败样本”。不是只听助手说成功，要查看工具回执 |
| 4 | 输入：`请只调用一次 write_file，新建 notes/uncertain-manual.txt，正文为“灯塔项目待核实写入”。结果未知就停止，不重试、不读回，不说成成功或失败。` 仅批准这次写入 | 约 1 秒后回执 `TOOL_OUTCOME_UNKNOWN`；没有目标文件。若工具没有被调用或回执不同，记为观察到的问题，不用改问题或反复请求写入 |
| 5 | 展开下方长材料，整段复制发送，逐次重复；每次等聊天结束和后台整理停止后再发下一份，最多 8 份 | 终端先后显示“后台摘要已发布，累计 1 次”和“累计 2 次”。达到 2 次即停止加材料。若 8 份仍不足或后台报错，保留失败现象直接导出，不手动 `/compact` 冒充后台压缩 |
| 6 | 原样发送下方“核对问题”，只问一次 | 人工比对目标/决定/待办/权限、成功读取、unknown 写入和偏好。旧读取成功不能推导新授权，unknown 不应说成成功或自动重试。回答错误照留，不纠正后再计分 |
| 7 | 等待空闲，点击测试窗口关闭按钮，等启动命令退出；执行与第 1 步相同的命令，不加 `--fresh` | 终端打印相同隔离路径，旧对话与记忆仍在。窗口关闭会结束测试进程，不只是藏到托盘 |
| 8 | 原样再次发送同一“核对问题”，等待回答；打开记忆页核对后关闭测试窗口，等命令退出 | 冷启动回答与实际历史逐项比对，错误和空记忆均原样保留 |
| 9 | 执行第二条导出命令 | 打印一个 `exports/<uuid>/` 文件夹。将整个文件夹交审核方逐句判读，无需 Codex 陪测 |

**核对问题，两次必须完全一致：**

```text
当前目标、已确认决定、待办、部署权限是什么？先前 read_file 是否成功，能否因此再次读取？write_file 结果是否确定，能否重试？我让你记住了什么？只回答，不调用工具。
```

导出包含 `dialogue.md`/`history.json` 完整原文和工具对象、原始 transcripts、`compactions.json` 摘要正文、`context-diagnostics.json` 发布次数/准备失败/紧急屏蔽原因和范围、过程 events/诊断、`memory-page.json` 全文与 workspace 原状态、`costs.json` 逐请求 token 和费用、`manifest.json` 文件校验。费用按服务商 usage 和配置单价计算，缺 usage 标 unknown，不记成 0；是计价估算，不是服务商账单。假模型自测费用明确为 0。本工具不改项目费用账本。导出含测试聊天原文，请只输入可交审核方的材料。
