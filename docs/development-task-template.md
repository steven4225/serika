# 开发任务输入模板

把下面填好后粘贴进 TUI。这是用户任务范围，不是执行权限：每次工具调用仍走现有 `y/n`；路径授权和 Docker 挂载才决定实际能做什么。

```text
目标：<希望修好的一个具体行为>
已知现象／复现步骤：<命令、输入、当前输出；未知就写未知>
允许读取的范围：<路径>
允许修改的路径：<路径>
禁止操作：<例如改测试、联网、提交、推送>
验证命令：<可直接运行且保留真实退出码的命令>
完成标准：<可由磁盘 diff 和实际测试输出核对的结果>
```

请先调查相关实现；可行时先复现，再做最小修改并运行指定验证。每次工具调用仍由 TUI 单独确认。最后报告实际修改、每条验证命令的工具 exitCode、未验证项和 Git 状态；不要把建议运行写成已通过。不要在验证命令后拼接 `echo` 或其他会掩盖退出码的命令。
