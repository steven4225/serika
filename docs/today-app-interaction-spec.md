# Today.app 操作逻辑规格（UI 无关）

- 来源：`today-app-功能逻辑完整报告-v3.md`（CDP 实测）
- 用途：冻结交互契约，供重新开发 UI；**不**约束像素、样式、组件库
- 排除：账号、邮箱、订阅账单、具体记忆正文、个人设备名等隐私内容
- 对照实现：换皮时尽量沿现有桌面 IPC（run／confirm／记忆／Telegram），不重写宿主契约

---

## 1. 产品分层（设计原则）

1. **对话即入口** — 创建任务不是表单，是对话；任务列表极简，用户描述意图即可。
2. **能力靠连接** — 应用／设备／技能／IM 四类连接决定能力边界；区分「已授权」与「可用」。
3. **记忆带溯源** — 事实标来源（单源 `from` vs 多源 `corroborated`），不是流水日志。
4. **关系拟人化** — 亲密度、助理第一人称日记、每日寄语（需主动揭晓）。
5. **触发克制** — 技能按上下文自动选；避免误触发；不要为选技能反问用户。

逻辑分层示意：

```
设置／能力连接层
Today 简报层 · 任务执行层 · 记忆认知层 · 关系层
        ↓
  常驻聊天栏 · 搜索 · 迷你聊天窗
```

---

## 2. 路由契约

| 路由 | 界面职责 |
|---|---|
| `/today` | 简报首页 |
| `/tasks` | 已建任务列表（极简） |
| `/tasks/new` | 对话式创建任务 |
| `/memories` | 记忆总览（分类卡片） |
| `/memories/<id>` | 某分类详情（结构化事实 + 来源） |
| `/profile` | 助理人格／关系页 |
| `/settings` | 设置 |
| `/connectors` | 连接应用 |
| `/devices` | 设备 |
| `/skills` | 技能 |
| `/channels` | 连接聊天工具（IM） |
| `/chat` | 迷你聊天（独立窗口） |

结构约定（可改像素，勿改职责）：

- 主窗：左侧**常驻聊天栏** + 右侧内容区（路由切换只换右侧）。
- 右侧顶栏 Tab：Today／任务／记忆／人格；另有搜索、设置入口、收起侧边栏。
- `/chat` 为独立迷你窗，快捷键唤起（产品现为 Option+空格）。

## 3. 各页行为契约

### 3.1 Today（`/today`）

- 时间维：昨天／今天。
- 简报类型：晨间／晚间。
- 首页只保留最近 brief；更早内容从聊天历史进入。

### 3.2 任务（`/tasks`）

- 入口：`创建任务` → 进入 `/tasks/new`（**不是**弹表单）。
- 子 Tab：任务／定时任务。
- 列表按日期分组；本身只是「已建任务」存放处。

### 3.3 创建任务（`/tasks/new`）

- 对话式：自然语言描述目标。
- 可提供示例提示（点击填入输入框）。
- 助理自行拆步／并行／依赖，或派后台 worker；用户不必先想清分解。
- 产品侧对应：任务代理执行 vs 自动化管理（职责分离）。

### 3.4 记忆（`/memories`）

- 总览：筛选（如全部／健康）+ 分类卡片（含条目数）。
- 详情：结构化分节；每条事实带来源标注（`from …`／`corroborated: A + B`）。
- 可有用户画像聚合卡。

### 3.5 人格／关系（`/profile`）

- 可编辑资料与头像。
- 亲密度：等级 + 数值 + 进度。
- 日记：助理第一人称、按日观察（非用户手写日记）。
- 每日寄语：默认未揭晓，用户点击后展示。

### 3.6 设置（`/settings`）

分组契约（实现可改文案，勿丢块）：

| 分组 | 要点 |
|---|---|
| 订阅 | 档位／试用／管理入口 |
| 模式 | 平衡（自动选模）／性能（固定强模）；互斥选择 |
| 月度用量 | 重置时间、剩余、立即重置、账单 |
| 能力与连接 | 跳转：连接应用／设备／技能／聊天工具 |
| 通用 | 账号、语言、运行时防止休眠 |
| 通知 | 消息通知、入会提醒等 |
| 键盘快捷键 | 快速聊天、聊天搜索、切换侧边栏 |
| 关于 | 关于、支持、社区、退出登录 |

导航：进入设置后「返回」回 Today；产品实测 ESC 无效——重建 UI 时可决定是否支持 ESC，但须有明确返回路径。

### 3.7 连接应用（`/connectors`）

- 分组：本机／云端／其他设备。
- 状态：已授权 vs 可用。
- 本机类：文件夹／桌面访问等；云端类：日历、通讯录、邮件、备忘录、提醒、操作电脑等。

### 3.8 设备（`/devices`）

- 列出已连接设备及在线／可用性状态（含云电脑）。
- 「连接更多」：Mac／Windows／Linux／iPhone／Android／浏览器插件等入口。

### 3.9 技能（`/skills`）

- 列表 + 添加技能。
- 每项：名称 + 领域用途摘要。
- 触发策略：上下文自动选择；克制误触发；不因选技能打扰用户。

### 3.10 聊天工具（`/channels`）

- 可选 IM（如 Telegram／Slack／Discord／WeChat）+ 连接按钮。
- 语义：在外部 IM 中与助理聊天。

### 3.11 迷你聊天（`/chat`）

- 独立窗口；快捷键唤起；与主窗聊天栏职责一致、形态更轻。

### 3.12 搜索

- 范围：消息／文件／链接／图片／全部。
- 键盘：上下导航、回车选择、ESC 关闭、Tab 切换筛选。

### 3.13 原生壳（若保留桌面壳）

- 菜单需覆盖：关于、检查更新、设置、退出、**退出并保留窗口**（关 UI 后台继续跑）。
- 与「运行时防止休眠」配套，支持后台常驻。

---

## 4. 重建 UI 时的硬约束

- **保留**：上表路由职责、五条原则、常驻聊天 + 右侧功能区的信息架构、确认／执行／记忆溯源等宿主能力入口。
- **可改**：像素、配色、组件、是否左右分栏、文案语气。
- **不要**：为换皮重写 run／confirm／记忆／Telegram 等宿主 IPC；不要用 UI 重开挤掉已定稿的数据长期可用项（历史整理、Telegram 生命周期、备份、回执持久化）。
- **优先级**：规格可先落地；真动前端须用户明确「插队」或「与项 1 并行」。
