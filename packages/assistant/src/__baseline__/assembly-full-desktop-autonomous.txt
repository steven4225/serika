## tool memory_stage_candidates

Only add accepts scope. Target edits require memoryId/expectedRevision and must omit scope entirely (even the unchanged scope); never copy pinned/enabled fields from the target. recallTerms (at most three, each 96 UTF-8 bytes) are lookup aids, not facts. Missing eligibility requires review; this enum is model judgment, not permission or proof. Ambiguous target/time needs review, not guessed dates. An empty proposals array means no suggestions. This only stages data; completed finalization applies the trusted host policy. In automatic mode only eligible incremental proposals are saved; the rest are not saved and have no user review queue. Review mode keeps them pending.
